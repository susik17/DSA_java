5.List Comprehension — Short Note

Purpose: Loop + condition- one line

[value for item in list]

With condition:

[value for item in list if condition]

Example:

[x for x in nums if x % 2 == 0]

→ nums- even numbers only

Subsets example:

[nums[i] for i in range(n) if mask & (1 << i)]
